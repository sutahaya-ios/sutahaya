# App Store申請チェックリスト

2026年9月〜10月に3回リジェクトされた。提出前にこの全項目を上から確認する。1つでも欠けると審査は通らない。

- 1回目: ガイドライン3.1.2 — 説明文に利用規約(EULA)のリンクが無い(App Store Connect側の設定漏れ)
- 2回目: ガイドライン2.1(b) — 有料アプリ契約が未締結で、課金商品の情報を取得できない(同上)
- 3回目: ガイドライン3.1.2 — **広告非表示を自動更新サブスクで売っていた**(商品設計の問題。設定では直らない)

> **3回目の教訓:** 自動更新サブスクは「継続的に価値が増えるサービス」向けで、**広告を消すだけの一度きりのアンロックは認められない**。買い切り(非消耗型)にすること。アプリ本体には指摘が無く、課金の商品タイプだけで3週間失った。

## H. 提出直前の最終確認

**ここを飛ばしたせいで落ちている。必ずやる。**

1. **課金商品が実際に取得できるか、自分の端末で見る**
   - マイページ →「プレミアム(広告非表示)」を開く
   - 「¥500」が出れば合格。「商品情報を取得できませんでした」なら**提出しない**
   - XcodeのStoreKit設定ファイルを使うと契約と無関係に表示されるため、
     Edit Scheme → Run → Options → StoreKit Configuration を **None** にして確認する
2. ビジネス画面に警告(黄色・赤)が残っていないか
3. 提出物の下書きに**アプリ本体と課金アイテムの2つ**が入っているか
4. 未実装の機能が押せる状態で残っていないか(ガイドライン2.1)

## I. 却下されたあとの出し直し

**却下された提出物を片付けないと、次の提出物にバージョンを追加できない。**

1. App Review →「iOSでの送信」で、**提出された項目をすべて削除**する(アプリバージョン・サブスクグループ・サブスク)
2. バージョンページの「審査用に追加」で、新しい下書きへバージョンを追加する
3. ボタンがグレーのままなら、まず**ブラウザを再読み込み**する。App Store Connectは状態の反映が遅れる
4. それでも押せなければ、ビルドの紐付けが外れていないか確認する

> 審査を自分で取り下げて出し直すと、**待ち順は最後尾に戻る**。9月は提出から結果まで2週間かかった。急いで取り下げない。
