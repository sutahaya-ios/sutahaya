# ストア掲載用の画像

App Store Connectへアップロードする素材の置き場所。開発中に撮った確認用のスクリーンショットは `docs/screenshots/` にあり、こことは用途が違う。

| ファイル | 用途 | サイズ |
|---|---|---|
| `appstore-screenshot-1.png`〜`5.png` | 製品ページのスクリーンショット。**番号順に並ぶ**ので、順番を変えるときはファイル名ごと入れ替える | 1320×2868(6.9インチ) |
| `app-icon-source.png` | アプリアイコンの元画像 | 1024×1024 |

## 注意

- スクリーンショットは**6.9インチだけ用意すれば、それ以下の画面サイズには自動で流用される**
- 現在の5枚は**v1.0.0時点の画面**。対戦リザルトを表彰台へ、開始画面をVS形式へ変更したため、**実際のアプリと食い違っている**。差し替えが必要
