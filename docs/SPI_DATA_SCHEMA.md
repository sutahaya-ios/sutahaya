# SPI問題データの形式(ver2)

英単語とは別スキーマ。英単語は誤答をシード時に自動生成するが、SPIは
**誤答も含めて作問時に確定させる**(計算過程のよくある間違いを誤答に置くことが
教材の質を決めるため、機械生成では作れない)。

決定事項:
- **解説は必須**。特に非言語は解説がないと復習にならない
- **SPIはレベル(★)で分けない**(2026年10月22日決定)。`difficulty` は必須項目なので `1` で統一し、アプリはSPIでは難易度を無視して全問を対象にする
- **出題範囲は形式(`format`)で選ぶ**。言語は下表の7形式。非言語の形式は未定(`null`)
- **選択肢は5つ**(本番のSPIに合わせる。英単語は4つのまま)
- **選択肢は出題時にシャッフルしない**。並びは変換時に確定させる(下記「変換ルール」)
- **下線部は【 】で囲む**。アプリは下線を描けないため。例:`【身に余る】処遇`
- 図表は**表だけver2で対応**する。グラフ・ベン図はver2.1以降

## JSON

置き場所: `HayaosiApp/Resources/spi_verbal.json` / `spi_nonverbal.json`
トップレベルは配列(既存の英単語JSONと同じ)。

```json
[
  {
    "id": "spi_n_0001",
    "difficulty": 1,
    "format": null,
    "text": "ある商品を1個800円で仕入れ、定価の2割引きで売ったところ、1個あたり160円の利益が出た。この商品の定価はいくらか。",
    "choices": ["960円", "1000円", "1150円", "1200円", "1250円"],
    "answer": "1200円",
    "explanation": "売価は 800 + 160 = 960円。売価は定価の8割なので、定価 = 960 ÷ 0.8 = 1200円。",
    "table": null
  }
]
```

| フィールド | 必須 | 内容 |
|---|---|---|
| `id` | ✅ | `spi_v_####`(言語) / `spi_n_####`(非言語)。カテゴリ内で重複禁止 |
| `difficulty` | ✅ | 1〜5。SPIは `1` で統一 |
| `format` | 言語は✅ | 出題形式(下表)。非言語は未定なので `null` |
| `text` | ✅ | 問題文 |
| `choices` | ✅ | 5つ。**この順で表示する**(並べ方は「変換ルール」) |
| `answer` | ✅ | 正解。`choices` のいずれかと完全一致すること |
| `explanation` | ✅ | 解説 |
| `table` | — | 表を使わないなら `null` |

### 言語の `format`

| 値 | 形式 | 問題数(第1弾) |
|---|---|---|
| `two_word_relation` | 二語の関係 | 20 |
| `word_meaning` | 語句の意味(説明→語、言い換え) | 20 |
| `word_usage` | 語句の用法(多義語、文法) | 20 |
| `sentence_order` | 文の並び替え(文章型、1文型) | 20 |
| `fill_blank` | 空欄補充(文章型、短文型) | 20 |
| `reading` | 長文読解(本文5本×設問2問。本文は設問ごとに繰り返す) | 10 |
| `kanji_compound` | 熟語の成り立ち | 20 |

### 表を持つ場合の `table`

```json
"table": {
  "caption": "3店舗の売上(万円)",
  "header": ["", "4月", "5月", "6月"],
  "rows": [
    ["A店", "120", "150", "130"],
    ["B店", "90", "110", "140"]
  ]
}
```

セルはすべて文字列。桁区切りや単位の扱いで揉めないよう、**表示したい形のまま**書く。

## 入力用xlsx

置き場所: `word_bank/spi.xlsx`(git管理外)。「言語」「非言語」の2シート。

| 列 | 必須 | 例 |
|---|---|---|
| `id` | ✅ | `spi_n_0001` |
| `difficulty` | ✅ | `3` |
| `text` | ✅ | 問題文 |
| `answer` | ✅ | `1200円` |
| `wrong1`〜`wrong4` | ✅ | `960円` / `1000円` / `1150円` / `1250円` |
| `explanation` | ✅ | 解説 |
| `table_caption` | — | `3店舗の売上(万円)` |
| `table_data` | — | セル内改行+カンマ区切り(下記) |
| `format` | 言語は✅ | `two_word_relation` など。非言語は空欄。既存の列位置を崩さないよう末尾に置く |

`table_data` の書き方:

```
,4月,5月,6月
A店,120,150,130
B店,90,110,140
```

1行目がヘッダー、2行目以降が本体。表を使わない問題は空欄のままでよい。

## 変換ルール(`word_bank_to_json.py` の拡張分)

1. `answer` と `wrong1`〜`wrong4` を1つの配列にまとめる
2. 並べ方は次の順で決める
   - 選択肢がア〜オ、または熟語の成り立ちの5種類なら、その決まった順に並べる
   - **5つすべてが数値として解釈できる場合は昇順に並べる**。数値の判定は、円・個・%・カンマなどを除いた残りが数値になるかで行う
   - それ以外は誤答の入力順を保ち、**IDのハッシュで決めた位置へ正解を差し込む**。入力順のままだと正解が常に先頭になるため
3. `table_data` を `header` と `rows` に分解する。空欄なら `table: null`
4. 同じシート内で `id` が重複していないか、`format` がシートの許す値かを検証する
5. `answer` が `choices` に含まれているか検証する
